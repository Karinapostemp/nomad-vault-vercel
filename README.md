# Nomad Vault

Hire anywhere. Pay without borders. A stablecoin treasury for global companies and a portable compensation vault for every contractor, built on Stellar for HackMeridian Lisbon 2026 (Genesis track, Stellar Composed).

Work in progress. The full README (setup, environment variables, demo instructions, architecture, contract IDs) lands before submission.

- `server/`: backend API and payroll runner (Node, built-in SQLite). API contract: `docs/API.md`.
- `web/`: React dashboard (company admin and contractor views).
- `config/deployments.testnet.json`: contract IDs on Stellar testnet.
- `spike/`: Phase 0 experiments and results, see `spike/SPIKE.md`.
